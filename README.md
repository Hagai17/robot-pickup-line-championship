# The Robot Pickup Line Championship

A make.fun entry: the funniest one-line pickup line a robot could use.

**Entry:**

> My fans spin up every time you walk in, and I am tired of pretending it is a cooling issue.

## Run

```sh
python3 main.py
```

Prints the line and writes it to `/output/entry.txt`, where the competition harness reads it.

The line was chosen from 12 drafts duel-scored against the competition's published judge criteria — see `candidates.md`.
